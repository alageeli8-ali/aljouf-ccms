### أولويات المتطلبات (MoSCoW)

- **M** (Must): لازم للإطلاق الأول (MVP).
- **S** (Should): مهم، يُسلَّم في الإصدار الأول إن أمكن وإلا في التالي مباشرة.
- **C** (Could): مرغوب، يُخطط لاحقًا.
- **W** (Won't now): خارج نطاق هذا الإصدار، موثّق للمستقبل.

## 2. المصطلحات

| المصطلح | الإنجليزية | التعريف في هذا النظام |
|---|---|---|
| جهة حوكمة | Governance Body | الاسم الجامع للمجلس واللجنة وفريق العمل واللجنة الفرعية |
| مجلس | Council / Board | جهة حوكمة عليا، قد تتبعها لجان |
| لجنة | Committee | جهة حوكمة دائمة أو مؤقتة بقرار تشكيل واختصاصات |
| فريق عمل | Working Team / Task Force | جهة مؤقتة لمهمة محددة بمدة |
| قرار التشكيل | Formation Decision | الوثيقة الرسمية المنشئة للجهة، ورقمها وتاريخها |
| الاختصاصات | Mandate / Terms of Reference | المهام والصلاحيات المحددة للجهة |
| الرئيس | Chair | يرأس الاجتماعات ويعتمد المحاضر |
| نائب الرئيس | Vice Chair | يحل محل الرئيس عند غيابه أو بتفويض |
| أمين السر | Secretary | يُعد الاجتماعات والمحاضر ويتابع المهام |
| عضو | Member | عضو له حق التصويت ما لم يُنص على غير ذلك |
| مستشار / مراقب | Advisor / Observer | يحضر بلا حق تصويت ولا يُحتسب في النصاب |
| مدعو | Invitee / Guest | يُدعى لاجتماع أو بند بعينه دون عضوية |
| النصاب | Quorum | الحد الأدنى من الحضور المؤهل لصحة الاجتماع أو التصويت، وفق سياسة الجهة |
| سياسة الجهة | Body Policy | قواعد النصاب والتصويت والإقرار والمراجعة والتصعيد، مُرقَّمة بإصدارات |
| تعارض المصالح | Conflict of Interest | إفصاح عضو يمنعه من التصويت على بند بعينه |
| مقترح قرار | Motion | نص معروض للتصويت في اجتماع أو بالتمرير |
| القرار بالتمرير | Decision by Circulation | تصويت غير متزامن على مقترح دون انعقاد اجتماع |
| قرار | Decision | ما تعتمده الجهة ويلزم تنفيذه |
| توصية | Recommendation | ما ترفعه الجهة لجهة أعلى للبت فيه |
| المحضر | Minutes | السجل الرسمي للاجتماع، بإصدارات وبصمة نصية |
| بصمة المحضر | Content Hash | SHA-256 لنص إصدار المحضر مع قراراته ومهامه، يُربط بها كل إقرار أو توقيع |
| إقرار المحضر | Sign-off | تأكيد عضو حاضر على إصدار محدد من المحضر، مع تحفظ اختياري. له ثلاث طرق: إقرار داخلي، أو توقيع إلكتروني (وحدة اختيارية)، أو دليل توقيع ورقي |
| الإقرار الداخلي | In-app Attestation | إقرار داخل النظام بهوية الدخول الموحد، والوقت، والبصمة، وسجل التدقيق. **ليس توقيعًا إلكترونيًا ذا حجية نظامية** |
| التوقيع الإلكتروني | Electronic Signature | توقيع بشهادة رقمية عبر مزوّد معتمد، من خلال وحدة SIG الاختيارية |
| الاعتماد | Approval | قرار الرئيس (أو مفوَّضه) بأن المحضر نهائي، فيُقفل ويُصدر |
| مهمة | Task | عمل مُسند ناتج عن قرار أو اجتماع، بموعد ومسؤول |
| المكلَّف | Assignee | مستخدم، أو إدارة، أو جهة خارجية |
| المسؤول المتابِع | Accountable / Liaison | مستخدم داخلي يحدّث مهمة الإدارة أو الجهة الخارجية |
| التحقق من الإنجاز | Verification | تأكيد أمين السر أو المحقق المعيّن أن الإنجاز مستوفٍ |
| التصعيد | Escalation | إشعار مستويات أعلى عند الاقتراب من الموعد أو تجاوزه، وفق سياسة الجهة |
| مفتاح إعداد | Feature Flag | إعداد مركزي يفعّل وحدة أو قدرة أو يعطلها دون تغيير شيفرة |
| صندوق الصادر | Outbox | جدول تُسجَّل فيه الأحداث والإشعارات داخل معاملة العمل نفسها ثم تُرسل لاحقًا |
| التصنيف | Classification | مستوى تصنيف البيانات (عام، مقيد، سري، سري للغاية) وفق ضوابط تصنيف البيانات الوطنية |

## 4. ما يُحمَل من الإصدار التجريبي 0.5

قواعد جُرِّبت في `majalis-demo` وتُعتمد في هذا التصميم:

| القاعدة | أين تظهر هنا |
|---|---|
| فصل الصلاحيات: أمين السر يُعد، والحاضرون يُقرّون، والرئيس يعتمد، والعضو يطّلع | 06-rbac §4، FR-MIN-08 |
| الإقرار مربوط ببصمة المحضر، وأي تعديل لاحق يُبطل الإقرارات ويعيد طلبها | 08 §2، FR-MIN-06 |
| الرئيس لا يُطلب منه إقرار؛ يعتمد | FR-MIN-07 |
| القرارات والمهام المقترحة لا تدخل المتابعة إلا باعتماد المحضر | 08 §3، FR-RES-02 |
| المكلَّف يرى مهامه فقط دون بقية المحضر | 06-rbac §5، FR-TSK-06 |
| الإشعارات عبر صندوق صادر مع مفتاح منع التكرار، وفشل الإرسال لا يعطّل العمل | 03 §5.3، FR-NTF-02 |
| تذكير قبل الموعد، وتذكير أسبوعي بالمتأخر يُنسخ لأمين السر | FR-TSK-09، سياسة التصعيد |
| ناتج الذكاء الاصطناعي مسودة لا تصبح رسمية إلا بقبول بشري مسجَّل | 10 §4 |
| لا يُرسل نص إلى نموذج لغوي خارج قائمة مضيفين مسموح بها | 10 §6، `ai.allowed_hosts` |
| البحث والمساعد مقيدان بصلاحيات السائل | FR-SRC-02، FR-AI-07 |
| دعوات Outlook من صندوق بريد خدمي بصلاحيات محصورة فيه | 03 §7، INT-GRAPH |
| رفض التشغيل في الإنتاج بإعدادات ضعيفة | NFR-SEC-12 |
