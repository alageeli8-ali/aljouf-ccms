## 4. حدود هذه المرحلة — بصراحة

1. **NuGet محجوب في بيئة العمل** (ADR-015): لم يُبنَ مسار Npgsql ولا صورة Docker هنا؛ الكود جاهز لهما ويُبنيان في خط تكامل له وصول إلى NuGet وMCR. أول خطوة في المرحلة 2 تشغيل الاختبارات نفسها على بناء Npgsql.
2. **الدخول الموحد غير مفعّل فعليًا**: الموصل مختبر على مزوّد وهمي فقط، ويعمل مع Entra ID حين تُسلَّم بيانات تسجيل التطبيق (Q-03).
3. **لا تكامل خارجي جاهز**: البريد والمراسلات والتوقيع والذكاء الاصطناعي تعرض حالة «غير مضبوط» حتى تتوفر واجهاتها وبيانات اعتمادها. المحاكي `sandbox` للتوقيع مسموح في غير الإنتاج فقط.
4. **دورة الحوكمة جزئية عن قصد**: جدولة الاجتماع، وطلب الإقرار والإقرار الداخلي، وإسناد المهام وتحديثها منفذة؛ النصاب والتصويت والاعتماد وإصدار القرارات بالترقيم والتصعيد والتحقق من الإنجاز في المراحل 2–4 (13).
5. **مؤجل إلى المرحلة 2**: قيد التصنيف مقابل التصريح في الصلاحيات، وتجاوزات المفاتيح على مستوى الجهة، وتقسيم حزمة الواجهة (1.6 م.ب حاليًا) بتحميل الصفحات عند الطلب.

## 5. التشغيل

```bash
# 1) قاعدة البيانات (مرة واحدة، بحساب مدير PostgreSQL)
psql -h 127.0.0.1 -p 5433 -U postgres -v owner_pw=... -v app_pw=... -v db=ccms_dev -f db/bootstrap.sql

# 2) الواجهة (تُبنى إلى wwwroot في Ccms.Host)
cd web && npm ci && npm run build && cd ..

# 3) الخلفية — التطوير يطبق الترحيلات عند الإقلاع
cd src/backend/Ccms.Host
ASPNETCORE_ENVIRONMENT=Development dotnet run -- seed-sample        # بيانات تجريبية (اختياري)
ASPNETCORE_ENVIRONMENT=Development dotnet run                       # http://localhost:5000 — /swagger للتوثيق
# حسابات تجريبية: admin|governance|ceo|auditor|chair|vice|secretary|member|observer|executor|manager|external @sample.jsdo.test
# كلمة المرور: Ccms@Sample2026

# 4) الاختبارات
dotnet run --project src/backend/Ccms.Tests -- docs/test-results/phase1-backend.md
cd web && npm test

# الإنتاج: dotnet Ccms.Host.dll migrate ثم bootstrap-admin --email ... --name ... ثم التشغيل (بناء -p:UseNpgsql=true)
```
