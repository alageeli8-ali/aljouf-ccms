| المستوى | الأداة | النطاق | متى |

## 2. البيانات والبيئات

- بيانات اختبار مولدة (لا بيانات حقيقية) بأسماء عربية واقعية، تشمل: 3 جهات بسياسات مختلفة (أغلبية، ثلثين مع اشتراط الرئيس، رقم ثابت)، وأعضاء خارجيين، وتعارض مصالح، وإنابة.
- مزوّدات وهمية لكل موصل (Graph، قمم، التوقيع `sandbox`، النموذج `mock`) تحاكي النجاح والفشل والمهلة.
- ساعة قابلة للتحكم (`IClock`) لاختبار التصعيد والمهل وأيام العمل والإجازات.

## 5. معايير الدخول والخروج

**الدخول لاختبار القبول:** كل اختبارات الوحدات والتكامل والعقد ناجحة؛ لا عيب مفتوح بخطورة حرجة أو عالية؛ مصفوفة المفاتيح ناجحة؛ البيئة مطابقة للإنتاج.

**الخروج للإطلاق:**
1. نجاح سيناريوهات القبول 01 §9 بتوقيع ممثلي المستخدمين.
2. لا ثغرات حرجة أو عالية مفتوحة من اختبار الاختراق؛ المتوسطة بخطة معالجة معتمدة.
3. تحقق أهداف الأداء NFR-PRF-01..04.
4. نجاح تمرين الاستعادة ضمن RPO/RTO.
5. فحص إتاحة الوصول دون مخالفات حرجة.
6. اكتمال دليل التشغيل وتسليم المعرفة لفريق التقنية.
